# 0001: choice of tech stack

## Context
Building a portfolio project to demonstrate a variety of backend concepts (e.g. auth, async processing). The framework choice is secondary

## Decision
Backend: FastAPI + PostgreSQL
Frontend: Next.js

## Alternative
- Vue.js for the frontend: already familiar with it from a prior project, which would shift the learning time more towards backend concepts

## Consequence
Next.js is new, so the frontend work will take longer than expected
